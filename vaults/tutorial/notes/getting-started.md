# Getting started

This file has no frontmatter. It is still a note.

Projector reads its title from the heading above and its id from the filename, so a folder
of ordinary markdown — an Obsidian vault, a directory of meeting notes — opens as a board
without being converted first.

Nothing is written back until you change something. The moment you give this note a status
or a priority, projector writes down the id it has been calling it by, so the note keeps
its identity even if the file is later renamed.
